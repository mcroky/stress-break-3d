# 스트레스 브레이크

브라우저에서 즐기는 3D 스트레스 해소 게임입니다. Node.js 20 이상이 필요하며 외부 패키지 설치는 필요하지 않습니다.

## 온라인 배포

[게임 바로 실행](https://mcroky.github.io/stress-break-3d/) · [GitHub 저장소](https://github.com/mcroky/stress-break-3d)

GitHub Pages는 `main` 브랜치에 푸시할 때 `.github/workflows/deploy.yml`을 통해 `public/`을 배포합니다. 게임 진행 상황은 접속한 브라우저에만 저장되며, 기기 사이에 동기화되지 않습니다.

상점에는 가격과 액션 포인트 보너스가 단계적으로 올라가는 아이템 50종이 있습니다.

## 로컬 실행

```bash
node server.js
```

브라우저에서 `http://localhost:3000`을 엽니다. 다른 포트를 쓰려면 `PORT=포트번호` 환경 변수를 설정하세요.

로그인 없이 바로 시작할 수 있습니다. 포인트, 구매한 아이템, 기록은 현재 브라우저의 `localStorage`에 자동 저장됩니다. 같은 컴퓨터라도 다른 브라우저나 시크릿 창에서는 기록이 공유되지 않습니다. 브라우저 데이터를 지우면 기록도 사라집니다.

배경음과 효과음은 첫 화면 클릭이나 키보드 액션 후 재생됩니다. 상단의 ♫, ✺ 버튼으로 각각 켜거나 끌 수 있습니다. 사운드는 브라우저에서 생성하며 외부 음원 파일이 필요하지 않습니다.

이전 버전의 `data/users.json` 기록이 있다면 상단 **로컬 기록 → 기존 기록 가져오기**에서 하나를 선택해 브라우저로 옮길 수 있습니다. 기존 파일은 자동으로 지우지 않습니다. 서버는 로컬 컴퓨터에서만 접속을 받습니다.

검사: `node tests/integration.mjs`
